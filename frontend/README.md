# Forms Frontend

Next.js frontend for forms builder + public form fill + results.

## Local run

```bash
npm install
npm run dev
```

Set API URL if needed:

```bash
NEXT_PUBLIC_API_URL=http://localhost:8080
```

Main routes:
- `/auth`
- `/dashboard`
- `/dashboard/forms/{id}/edit`
- `/dashboard/forms/{id}/results`
- `/f/{slug}`
